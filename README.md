# Gran Sasso 2024
Scripts accompanying the Data Note on the Gran Sasso 2024 data

## Example scripts
The scripts `code_gran_sasso_csv.R` and `code_gran_sasso_excel.R` are example scripts to aid in the analysis setup by importing data and wrangling in a different format if necessary. For these scripts, either the CSV files (csv version) or the Excel spreadsheet (excel version) are assumed to be in a "data" subfolder inside an R project folder.

## Paper scripts
The scripts `richness.R` and `plots_tables.R` were used to produce figures and tables for the Data Note. These also constitute useful examples of how to utilize the dataset.
